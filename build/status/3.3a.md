## Design questions

- P3.3-02 expects the `demo` adapter to report `not_active` for a struck-off lawyer. The mock serves the raw status `struck_off`, as the lawyer's data. The adapter (task 3.3 proper) has to map `struck_off` and `lapsed` to `not_active`. I did not change the mock to match, because the spec only says "struck off".
