## Files created

- `.github/workflows/ci.yml`: pull requests only. Jobs: `checks` (lint, typecheck, OpenSSL 3 check, `pnpm test`), `browser` (Playwright Chromium and WebKit, then `LEGX_BROWSER=1 pnpm vitest run --project browser --project vault-browser --project core-browser`), `integration` (postgres:18.6-trixie service, `rippleci/xrpld:3.4.1` via `docker run --standalone` with `ci/` mounted at `/etc/xrpld/`, `XRPLD_WS=ws://127.0.0.1:6006`, `LEGX_PG_URL`, and the per-package `LEGX_32_*`, `LEGX_39_*`, `LEGX_310_*` overrides pointed at the CI services). Node matrix 24.22 and 26 on every job. pnpm 12.11.2 via `pnpm/action-setup@v6`, store cache via `actions/setup-node@v7`.
- `.github/workflows/nightly.yml`: `schedule` (03:17 UTC) and `workflow_dispatch`. Jobs: `fuzz` (matrix core, contracts, zk, `LEGX_FUZZ_SECONDS=600`), `mutation` (matrix critical and rest, `pnpm exec stryker run`), `quint` (Temurin 21, `sh spec/check.sh all`), `testnet` (`LEGX_NIGHTLY=1 LEGX_TESTNET=1`, runs `network.int.test.ts` and `frost-testnet.int.test.ts`), `zk` (`LEGX_LIVE_SEPOLIA=1`, `services/zk-verifier`, optional `SEPOLIA_RPC_URL` secrets), `model` (`LEGX_MODEL_RUNS=200`, `services/coordinator/test-int/model.int.test.ts`, xrpld and postgres), and `open-issue` (`actions/github-script`, runs on any failure in the jobs above, opens an issue linking the run log). Nothing in the nightly runs on pull requests.
