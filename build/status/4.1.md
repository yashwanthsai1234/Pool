## Known gaps
- Slow-3G throttling of the phone routes is not done (needs CDP network emulation; Chromium only). Part 2 can add it with `page.context().newCDPSession`.
- P4.1-05 is not tested over a real HTTP LAN IP. Needs a non-localhost origin in Playwright. The condition itself is tested.
- The CSP is a `<meta>` tag in the build plus a header on the Vite preview. `frame-ancestors` cannot be set by meta; the production server (task 3.7) must send the CSP as a header and add `frame-ancestors 'none'`.
- The dev server runs without CSP (React refresh needs inline scripts).
- The phone icons are plain coloured squares (placeholders).
- CI wiring: the budget check is `pnpm --filter @legx/web build && pnpm --filter @legx/web check:budget` and also runs inside the build test. No CI workflow file was written (outside this task's folders).
