## Research notes
SDK 0.19.2 typings: `request()` returns a QueryBuilder, `done()` gives `{url, onRequestReceived, onGeneratingProof, onProofGenerated, onResult, onReject, onError}`. `onResult` is deprecated in the typings (its `verified` flag can be tampered with); we never trust it, the proofs go to the server route and the console. URLs in `apps/web/SOURCES.md`.

## Deviations
- The task text says `@legx/zk` request builders; those load the SDK through Node `createRequire`, so the web app has its own small builder (same calls and the same core recipes).
- Error code for another identifier is `ZK_IDENTIFIER_MISMATCH` (console), core's own code is `IDENTIFIER_MISMATCH`.
